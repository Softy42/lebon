# Publications sur IONOS

- Ne jamais lancer de publication sur IONOS sans l’accord explicite de Sophie pour la publication concernée. Cette règle couvre le workflow GitHub de publication et les téléversements FTP/SFTP effectués par l’agent.
- Une autorisation de commit ou de push vers GitHub n’autorise pas une publication sur IONOS.
- Un accord donné pour une publication passée ne vaut pas autorisation pour une nouvelle publication.
